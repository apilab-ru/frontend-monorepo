Grouping Rules

One rule per line: includes|issue or comment:value1,value2|optional name

Enable “Group by rules” above to apply these rules.

Rule tips and examples

Write one rule per line. Match part of an issue or comment, then optionally name the group:

includes|comment:daily,meeting,1x1|Meetings includes|issue:TECH-|Technical work
  • Separate alternative matches with commas, without spaces: daily,meeting. Any match is enough.
  • Comments are lowercased before matching. Use lowercase keywords for comments; issue keys are case-sensitive.
  • The first matching rule wins. Put specific rules before broader ones.
  • A group name is optional. Named rules combine matching entries into that group, even when grouping by task or comment is also enabled.
  • Unmatched entries follow the other enabled grouping options, or go into develop when none apply.
